The standard library (`Lib/std`) is an ordinary Kairo library named `kairo::std`, spelled `std`. Nothing in it is implicit: write `import std::io` and call `io::println`.

| Page | Contents |
| --- | --- |
| [std::io](/docs/library/std/io/) | Printing to standard output and standard error. |
| [std::env](/docs/library/std/env/) | The process's view of its host. |
| [std::mem](/docs/library/std/mem/) | Heap allocation, re-exported from the core library. |
| [std::ctypes](/docs/library/std/ctypes/) | Types for talking to C and C++ that Kairo's primitives do not cover. |
| [std::rt::Float8](/docs/library/std/rt-float8/) | The OCP FP8 formats F8E4M3 and F8E5M2 as library structs. |

## Root re-exports

```kairo
pub import io
```

The `std::io` module: `print`, `println`, `eprint`, `eprintln` and `flush`.

```kairo
pub import env
```

The `std::env` module: the process's view of its host (`exe_path`).

```kairo
pub import ctypes::*
```

C and C++ character types (`c_char`, `c_wchar`, `c_char16`, `c_char8`), re-exported at
the std root, so they are spelled `std::c_char` and so on.

```kairo
pub import mem::*
```

The allocation API from `std::mem` (`create`, `destroy`, `AllocatorScope`, ...),
re-exported at the std root.
