## `__builtin_c_char`

```kairo
type __builtin_c_char = u8
```

C and C++'s plain `char`, a character type distinct from `i8` and `u8`. Users spell it
`std::c_char`.

The `u8` body is only what parses; the type is the `CChar` lang item, which C++ spells `char`.

## `__builtin_c_wchar`

```kairo
type __builtin_c_wchar = u32
```

C++'s `wchar_t`, the `CWChar` lang item. Users spell it `std::c_wchar`.

Distinct from every integer type. The `u32` body is only what parses; the type store lays it
out from the target (16 bits wide on Windows).

## Operators

`x ^^ n` on a primitive base is lowered to a call to `pow`. The function is private, so it is documented here rather than called by name.

### `pow`

```kairo
fn <B: type, E: type> pow(base: B, exp: E) -> B
```

Implements `^^` on a primitive base: `x ^^ n` is lowered to `pow(x, n)`.

Repeated squaring, so overflow is exactly `*`'s. A negative exponent is `(1 / base) ^^ -exp`
under the base type's own division: for an integer base that reciprocal is 0, 1 or -1 and
nothing can overflow on the way back; for a float base it is the reciprocal. The exponent
negation is written `-(exp + 1)` rather than `-exp`, which has no value for the minimum.

`: type` rather than a bound: `B` and `E` are only ever primitives and no interface says
"numeric" yet, so C++ checks this one body per instance.
